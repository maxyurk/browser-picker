# Project website

`index.html` is a static one-page website. It uses local images, system fonts, plain CSS, and a small progressive-enhancement script. No package installation, build step, analytics, or external runtime is required.

## Preview

From the repository root:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory docs
```

Open `http://127.0.0.1:8000`. Stop the server with Control-C. The page also opens directly from disk; clipboard copying may be unavailable in that context, and the command remains selectable.

## GitHub Pages

The project website is published at **https://maxyurk.github.io/browser-picker/** from the **main** branch's **/docs** directory in [maxyurk/browser-picker](https://github.com/maxyurk/browser-picker).

Push website changes to `main` to trigger publication. The repository's **Settings → Pages** publishing source is **Deploy from a branch → main → /docs**. GitHub manages the deployment; no custom workflow is needed.

The `.nojekyll` file enables direct static serving. All asset URLs are relative, so the site works at both an account root and a project path.

See [GitHub's publishing-source instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) for the current Pages setup flow.

The public repository URL is configured in `index.html`, and source links also work without JavaScript. When moving the website to another repository, update the repository metadata, source links, canonical URL, and Open Graph URLs:

```html
<meta name="repository" content="https://github.com/OWNER/REPOSITORY">
```

Without configured metadata, JavaScript can infer the repository on a standard `<owner>.github.io/<repository>/` URL. Avoid adding a release download link until a release actually exists.

## Update assets and copy

- `assets/app-icon.png` and `assets/favicon.png` come from the original app icon generated by `scripts/make-icon.swift`.
- `./scripts/screenshots.sh` regenerates five native screenshots using neutral fixture data. The images are shared with the main README.
- `license.txt` is an exact copy of the root MIT license. Keep both copies in sync.
- `index.html` contains the product copy; `styles.css` controls layout; `site.js` handles screenshot mode, copying the install command, and optional repository links.

Before publishing, check desktop and mobile layouts, keyboard navigation, screenshot switching, install-command copying, and all links. The page remains usable when JavaScript is disabled and respects reduced-motion preferences.
