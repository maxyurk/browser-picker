A few useful details

Before your first click.

How do I open it if macOS shows a warning?

The app is not Apple-notarized, so macOS may block its first launch. After reviewing the source and release, try opening Browser Picker from Applications and dismiss the warning. Then open System Settings → Privacy & Security, scroll to Security, and choose Open Anyway for Browser Picker. Confirm Open and authenticate if asked. macOS remembers the exception for this app; no Terminal command or system-wide security change is needed. Apple's first-launch guide.

Which browsers and profiles are supported?

Any macOS browser can open regular links, including Safari, Chrome, Firefox, Edge, Brave, Vivaldi, Opera, Arc, Zen, and Orion. Browsers are discovered from macOS metadata; use Add browser… for anything missing. Profile and private-window routing are available for compatible Chromium browsers that publish their profile-root metadata. Other browsers use their regular URL handlers.

Can I open local files?

Yes. Choose Open With → Browser Picker, drop a file onto the app, or send a file URL. Any file type goes to your chosen browser, which decides how to display it. Files use your picker or default browser; website remembering applies to web links.

Does it change links inside a browser?

Browser Picker handles external HTTP and HTTPS links and files sent to it by macOS. Links clicked inside a browser stay there unless explicitly sent to this app. Universal links may go directly to their associated app.

What happens if I click outside?

The current picker closes without opening its link. Any other queued links pause. Resume them from the menu bar, reopen the app, or send a new link. You can turn this behavior off in General settings.

How do I switch back?

Choose another default web browser in System Settings → Desktop & Dock, disable Launch at login if you enabled it, then quit Browser Picker.
